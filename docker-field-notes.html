Docker Field Notes · Hands-on Lab

What this path is for

This Docker path is built for infrastructure, security, and operations professionals who need practical container skills before operating Kubernetes workloads.

Field note: Docker helps you build and run containers locally. Kubernetes schedules and operates containers across a cluster. Docker knowledge makes Kubernetes easier.

Recommended path

Docker Foundations

1. What Containers Actually Are

Understand containers as isolated application processes, not tiny virtual machines.

Docker Foundations

2. Images, Containers, and Registries

Learn images, running containers, tags, layers, and registries.

Image Build

3. Building a Simple Image

Create a small static web app image and run it locally.

Image Build

4. Dockerfiles Explained Practically

Understand Dockerfile instructions, image layers, build context, and safer build habits.

Container Operations

5. Volumes and Persistent Data

Container Operations

6. Networks and Port Mapping

Learn host ports, container ports, Docker networks, and container DNS.

Local Lab Orchestration

7. Docker Compose for Local Labs

Use Compose to run multi-container lab environments with repeatable configuration.

Troubleshooting

8. Container Logs and Troubleshooting

Diagnose stopped containers, port conflicts, bad commands, image issues, and application errors.

Container Security

9. Image Security Basics

Learn practical image security habits: trusted images, version pinning, non-root users, secrets, and scanning.

Final Project

10. Final Project: Containerize a Web App

Build, run, inspect, troubleshoot, and review a containerized web app using the full Docker path.

How this connects to Kubernetes

After you can build, run, inspect, troubleshoot, and package containers locally, the Kubernetes path will make more sense.
