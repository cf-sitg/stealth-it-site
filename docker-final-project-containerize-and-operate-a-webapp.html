Docker Final Project

Final Project: Containerize and Operate a Web App

Build, run, inspect, troubleshoot, secure-review, and operate a containerized web app using the full Docker path.

Docker Field Notes · Practical Skills Path

Docker skills alignment

Foundations Runtime Image Build Storage Networking Compose Security

Scenario

You have been asked to containerize a small internal web application for a local lab. The application must be built into a versioned image, run locally, expose the correct port, be repeatable with Compose, be inspectable through logs and Docker metadata, and pass a basic image hygiene review.

Project requirements

  • Create a project folder.
  • Create a custom index.html.
  • Create a Dockerfile using an intentional base image tag.
  • Create a .dockerignore.
  • Build a versioned image.
  • Run it manually on port 8090.
  • View logs and inspect the container.
  • Break and fix a port mapping issue.
  • Break and fix a bad image tag issue.
  • Create a Compose file.
  • Run the app with Compose.
  • Perform a security and operations review.

Step 1: Create the project

mkdir docker-final-webapp-v2
cd docker-final-webapp-v2

Step 2: Create index.html

<!DOCTYPE html>
<html>
<head>
  <title>Docker Final Project</title>
</head>
<body>
  <h1>Docker Final Project Complete</h1>
  <p>This web app is running inside a custom Docker image.</p>
  <p>The container was built, run, inspected, troubleshot, and reviewed.</p>
</body>
</html>

Step 3: Create Dockerfile

FROM nginx:1.27

COPY index.html /usr/share/nginx/html/index.html

EXPOSE 80

Step 4: Create .dockerignore

.git
.env
*.key
*.pem
secrets*
node_modules
*.log
tmp

Step 5: Build and run

docker build -t stealth-docker-final-webapp:2.0 .
docker run --name docker-final-webapp-v2 -d -p 8090:80 stealth-docker-final-webapp:2.0

Open http://localhost:8090.

Step 6: Validate and inspect

docker ps
docker logs docker-final-webapp-v2
docker inspect docker-final-webapp-v2
docker image inspect stealth-docker-final-webapp:2.0
docker history stealth-docker-final-webapp:2.0

Step 7: Break and fix port mapping

docker stop docker-final-webapp-v2
docker rm docker-final-webapp-v2
docker run --name docker-final-webapp-v2 -d stealth-docker-final-webapp:2.0
docker ps
docker inspect docker-final-webapp-v2

The app is running but not reachable from the host because no port was published. Fix it: 

docker stop docker-final-webapp-v2
docker rm docker-final-webapp-v2
docker run --name docker-final-webapp-v2 -d -p 8090:80 stealth-docker-final-webapp:2.0

Step 8: Break and fix a bad tag

docker run --name bad-tag-final nginx:not-a-real-final-tag

Read the error. Then run a real tag: 

docker run --name good-tag-final -d nginx:1.27
docker stop good-tag-final
docker rm good-tag-final

Step 9: Add Compose

Create compose.yaml: 

services:
  web:
    image: stealth-docker-final-webapp:2.0
    ports:
      - "8090:80"
    restart: unless-stopped

Replace manual run with Compose: 

docker stop docker-final-webapp-v2
docker rm docker-final-webapp-v2
docker compose up -d
docker compose ps
docker compose logs

Step 10: Final review checklist

  • Is the app built from a Dockerfile?
  • Is the image versioned?
  • Does .dockerignore exclude sensitive and unnecessary files?
  • Can you run the app manually?
  • Can you run the app with Compose?
  • Can you explain host port vs container port?
  • Can you view logs?
  • Can you inspect image and container metadata?
  • Can you recover from a missing port mapping?
  • Can you recognize a bad image tag error?
  • Can you explain what should change before production?

Step 11: Clean up

docker compose down
docker rmi stealth-docker-final-webapp:2.0
Bottom line: You have now built, run, inspected, troubleshot, and operationally reviewed a containerized web application. That is the right foundation before handing workloads to Kubernetes.
