Docker Foundations

Images, Containers, and Registries

Images are the packaged source of containers. Registries store images, and tags identify versions or labels.

Docker Field Notes · Hands-on Lab

Images

An image is a packaged application filesystem and metadata used to create containers.

Containers

A container is a running instance of an image.

Registries and tags

Registries store images. Tags identify image versions or labels, but tags like latest can change over time.

Hands-on lab commands

docker pull nginx:latest
docker images
docker image inspect nginx:latest
docker run --name image-lab -d -p 8081:80 nginx:latest
docker stop image-lab
docker rm image-lab
docker rmi nginx:latest
Bottom line: This lesson builds the practical Docker foundation needed before moving into orchestrated Kubernetes workloads.
