Final scenario

You are asked to build a Kubernetes-hosted SOC lab using Wazuh, validate monitoring visibility, generate safe test events, investigate alerts, write a tuning note, produce an incident-style summary, and document cleanup.

Project deliverables

  • Namespace plan
  • Wazuh deployment validation
  • Dashboard access method
  • Agent or monitoring visibility note
  • Safe test event log
  • Alert investigation worksheet
  • Detection/tuning note
  • Incident-style summary
  • Cleanup procedure

Step 1: Validate platform

kubectl config current-context
kubectl get nodes
kubectl get pods -A
kubectl get storageclass

Step 2: Validate Wazuh

kubectl get all -n wazuh
kubectl get pvc -n wazuh
kubectl get svc -n wazuh
kubectl get events -n wazuh --sort-by=.lastTimestamp

Step 3: Access dashboard

kubectl get svc -n wazuh
kubectl port-forward -n wazuh svc/<dashboard-service-name> 5601:5601

Step 4: Generate a safe test event

kubectl create namespace soc-lab --dry-run=client -o yaml | kubectl apply -f -
kubectl -n soc-lab create deployment final-soc-demo --image=nginx:latest
kubectl -n soc-lab exec -it deploy/final-soc-demo -- /bin/sh -c "echo final SOC lab test > /tmp/final-soc-test.txt && cat /tmp/final-soc-test.txt"

Step 5: Investigate in Wazuh

Search for activity around the test timestamp. Record source, rule, severity, description, and full-log summary.
