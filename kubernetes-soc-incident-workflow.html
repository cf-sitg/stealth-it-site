Step 4: Decide response actions

Containment:

- Isolate endpoint
- Stop workload
- Restrict namespace
- Disable account
- Block network path

Remediation:
- Remove unwanted file/process
- Patch system
- Correct configuration
- Rotate secret
- Update deployment
- Improve monitoring

Step 6: Close or escalate

Most lab events should close as expected activity. The purpose is to practice the workflow, not invent drama. Escalate only when evidence supports it.

Bottom line: Incident response is a structured decision process. The quality of the response depends on evidence, scope, timeline, and clear reasoning.
