Docker Security

Image Security Basics

Container security starts with the image: what you build from, what you include, what you expose, and how you maintain it.

Docker Field Notes · Hands-on Lab

Trusted images

Use trusted or organization-approved base images.

Version pinning

Avoid relying blindly on latest for production-style work.

Secrets

Never bake real secrets into Dockerfiles, copied files, image layers, or source repositories.

Image hygiene

Use .dockerignore, keep images small, run as non-root where practical, scan images, and rebuild when base images need updates.
