Volumes and Persistent Data

Containers are disposable, but some data needs to survive. Volumes and bind mounts separate data from container lifecycle.

Docker Field Notes · Hands-on Lab

Container filesystem

Data written only inside a container filesystem can disappear when the container is removed.

Named volumes

A named volume is Docker-managed persistent storage.

Bind mounts

A bind mount maps a host folder into a container and is useful for local development and labs.

Hands-on lab commands

docker volume create docker-data-lab
docker run --name volume-writer -v docker-data-lab:/data busybox:latest sh -c "echo persistent-data > /data/message.txt"
docker rm volume-writer
docker run --name volume-reader -v docker-data-lab:/data busybox:latest cat /data/message.txt
docker rm volume-reader
docker volume rm docker-data-lab
Bottom line: This lesson builds the practical Docker foundation needed before moving into orchestrated Kubernetes workloads.
