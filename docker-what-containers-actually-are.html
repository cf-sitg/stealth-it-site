Docker Foundations

What Containers Actually Are

Containers are isolated application processes created from images. This lesson shows how to run, inspect, log, exec into, stop, and remove a container.

Docker Field Notes · Hands-on Lab

What this lesson covers

A container is a running application process with a packaged filesystem and runtime isolation. It is not a full virtual machine.

Container vs virtual machine

Virtual machines include a guest operating system. Containers share the host kernel and package the application with its dependencies.

What Docker gives you

Docker provides tooling to pull images, start containers, map ports, inspect runtime settings, view logs, and clean up containers.
