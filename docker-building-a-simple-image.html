Docker Image Build

Building a Simple Image

The fastest way to understand images is to build one. This lab packages a small web page into a custom nginx image.

Docker Field Notes · Hands-on Lab

Project goal

Create a simple index.html file, write a Dockerfile, build a tagged image, and run that image locally.

Build context

The dot at the end of docker build means Docker can use the current folder as the build context.

Versioning

Build a new tag when application content changes so you can tell versions apart.

Hands-on lab commands

mkdir docker-simple-image-lab
cd docker-simple-image-lab
# create index.html
# create Dockerfile with:
# FROM nginx:1.27
# COPY index.html /usr/share/nginx/html/index.html
docker build -t stealth-simple-web:1.0 .
docker run --name stealth-simple-web-lab -d -p 8082:80 stealth-simple-web:1.0
docker logs stealth-simple-web-lab
docker stop stealth-simple-web-lab
docker rm stealth-simple-web-lab
Bottom line: This lesson builds the practical Docker foundation needed before moving into orchestrated Kubernetes workloads.
