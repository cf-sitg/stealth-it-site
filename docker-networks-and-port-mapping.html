Networks and Port Mapping

Containers need networking to receive traffic and communicate with each other. Port mappings and Docker networks are the starting point.

Docker Field Notes · Hands-on Lab

Port mapping

A mapping like -p 8080:80 maps host port 8080 to container port 80.

User-defined networks

Containers on the same user-defined Docker network can communicate by container name.

Localhost warning

Inside a container, localhost means that same container, not the host or another container.

Hands-on lab commands

docker run --name network-nginx-lab -d -p 8083:80 nginx:latest
docker network create app-network-lab
docker run --name web-on-network -d --network app-network-lab nginx:latest
docker run --rm --network app-network-lab busybox:latest wget -qO- http://web-on-network
docker network inspect app-network-lab
docker stop network-nginx-lab web-on-network
docker rm network-nginx-lab web-on-network
docker network rm app-network-lab
Bottom line: This lesson builds the practical Docker foundation needed before moving into orchestrated Kubernetes workloads.
