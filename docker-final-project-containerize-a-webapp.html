Docker Final Project

Final Project: Containerize a Web App

This final Docker project proves you can build, run, inspect, troubleshoot, and package a simple containerized web app before moving into Kubernetes.

Docker Field Notes · Hands-on Lab

Scenario

You have been asked to containerize a small static web application for a local lab.

Requirements

Create index.html, Dockerfile, .dockerignore, a tagged image, a running container on port 8086, a Compose file, and a troubleshooting test.

Final review

Prove you can build, run, inspect logs, inspect the container, explain port mapping, break and fix a port issue, and start the app with Compose.

Hands-on lab commands

mkdir docker-final-webapp
cd docker-final-webapp
# create index.html
# create Dockerfile using nginx:1.27
# create .dockerignore
docker build -t stealth-docker-final-webapp:1.0 .
docker run --name docker-final-webapp -d -p 8086:80 stealth-docker-final-webapp:1.0
docker ps
docker logs docker-final-webapp
docker inspect docker-final-webapp
# break it: run without -p, then fix it
# create compose.yaml
docker compose up -d
docker compose logs
docker compose down
docker rmi stealth-docker-final-webapp:1.0
Bottom line: This lesson builds the practical Docker foundation needed before moving into orchestrated Kubernetes workloads.
