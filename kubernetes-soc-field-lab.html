Kubernetes SOC Field Lab

Build a hands-on SOC lab on Kubernetes using Wazuh.

A hands-on SOC lab built on Kubernetes using Wazuh to teach security monitoring, SIEM operations, alert investigation, detection notes, and incident workflow.

What this path is for

This lab series builds on Kubernetes Field Notes and uses Wazuh to create a practical SOC-style environment. The goal is not to create a production SOC in a laptop lab. The goal is to understand security monitoring, Kubernetes operations, SIEM visibility, alert triage, detection notes, incident workflow, and cleanup.

Field note: A SOC lab should be safe, repeatable, and explainable. You should know what you deployed, what it monitors, what evidence supports an alert, and what you would document for follow-up.

Recommended path

Work through these lessons in order. The path starts with SOC concepts, moves into Wazuh-on-Kubernetes deployment, then finishes with alert investigation and incident workflow.

SOC Foundations

1. What a SOC Lab Actually Is

Define SOC, SIEM, XDR, telemetry, alerts, triage, investigations, findings, and the purpose of a safe lab.

Platform Operations

2. Kubernetes SOC Lab Architecture

Design the lab namespaces, Wazuh components, storage, access path, monitored workloads, and analyst workflow.

Platform Operations

3. Preparing the Kubernetes Lab for Wazuh

Validate the Kubernetes lab before deploying Wazuh: nodes, storage, namespaces, resources, DNS, and baseline troubleshooting commands.

SIEM Operations

4. Deploying Wazuh on Kubernetes

Deploy Wazuh into Kubernetes using the official Wazuh Kubernetes deployment model and validate the resulting pods, services, storage, and secrets.

SIEM Operations

5. Understanding the Wazuh Components

Understand the Wazuh manager, indexer, dashboard, agents, services, StatefulSets, Deployments, persistent volumes, and secrets.

SIEM Operations

6. Accessing the Wazuh Dashboard Safely

Access the Wazuh dashboard safely in a local lab using port-forwarding, then understand how production access differs.

Kubernetes Security

7. Deploying Wazuh Agents in Kubernetes

Understand Wazuh agent deployment models in Kubernetes, including DaemonSet and sidecar patterns, and validate agent visibility.

Detection Engineering

8. Generating Test Security Events

Generate safe lab events that create useful SOC telemetry without teaching exploit behavior.

Incident Response

9. Investigating Alerts in Wazuh

Triage Wazuh alerts using timestamp, source, rule, severity, description, full log, scope, and recommended action.

Detection Engineering

10. Detection and Tuning Notes

Write practical detection notes, false-positive notes, tuning recommendations, and alert-quality observations.

Incident Response

11. SOC Incident Workflow

Turn an alert into a structured SOC investigation with triage, scope, evidence, impact, containment, remediation, and lessons learned.

Final Project

12. Final Project: Build and Operate a Kubernetes SOC Lab

Deploy the SOC lab, validate Wazuh, onboard monitoring, generate test events, investigate alerts, write findings, and document cleanup.

Official documentation anchor

The deployment lessons intentionally point readers back to the official Wazuh documentation for the current Kubernetes deployment manifests and installation commands. This keeps the lab stable as Wazuh versions and Kubernetes deployment details change.

Lab note: This is a practical training path, not an official Wazuh certification course, not a production deployment guide, and not a guarantee that every Wazuh version will use the same manifests, services, credentials, or resource names. Always validate against the current Wazuh documentation before deploying.
