Docker Compose

Docker Compose for Local Labs

Docker Compose defines local multi-container labs in one YAML file instead of long manual docker run commands.

Docker Field Notes · Hands-on Lab

What Compose solves

Compose makes local environments repeatable by defining services, ports, volumes, networks, commands, and environment settings.

Service names

Compose services can usually reach each other by service name on the Compose network.

Cleanup

docker compose down stops and removes the Compose containers and default network.

Hands-on lab commands

docker compose version
mkdir docker-compose-lab
cd docker-compose-lab
# create compose.yaml
docker compose up -d
docker compose ps
docker compose logs
docker compose exec toolbox wget -qO- http://web
docker compose down
Bottom line: This lesson builds the practical Docker foundation needed before moving into orchestrated Kubernetes workloads.
